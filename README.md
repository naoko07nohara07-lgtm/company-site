# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ（Skyline Technologies）」のコーポレートサイトです。
HTML・CSS・JavaScript を 1 つのファイル（`index.html`）にまとめた、1 ページ構成のサイトです。

> ※ 本サイトに登場する会社名・住所・電話番号・メールアドレス・実績などはすべて架空のものです。

## 概要

### ページ構成

| セクション | 内容 |
| --- | --- |
| ヘッダー | ロゴ・ナビゲーション（スマホではハンバーガーメニュー） |
| お知らせ欄 | ナビゲーション直下に最新のお知らせを自動切り替えで表示 |
| ヒーロー | キャッチコピーと夜景のスカイラインのビジュアル |
| 企業理念（About） | ミッションと 3 つのバリュー |
| 事業内容（Services） | クラウド基盤構築・AI・Web アプリ・モバイルアプリ・UI/UX デザイン・DX コンサルティング |
| 実績数値 | 開発実績・顧客継続率などをカウントアップ表示 |
| 導入事例（Works） | 物流・医療・小売の 3 事例 |
| 開発の流れ（Flow） | ヒアリングからリリース・運用までの 5 ステップ |
| お知らせ（News） | ニュース一覧 |
| 採用情報（Recruit） | 募集職種の一覧 |
| お問い合わせ（Contact） | 会社情報と問い合わせフォーム |

### 主な機能

- レスポンシブデザイン（PC・タブレット・スマートフォン対応）
- スクロールに合わせたフェードイン表示
- お知らせ欄の自動切り替え（マウスオーバー中は停止、× ボタンで非表示）
- お問い合わせフォームの入力チェック
  - ※ デモのため、実際には送信されません
- OS でアニメーションを減らす設定にしている環境では、アニメーションを無効化

```
company site/

```

## ブラウザで index.html を開く手順

ビルドやサーバーの起動は不要です。`index.html` をブラウザで開くだけで表示できます。

### 方法 1：ダブルクリックで開く（最も簡単）

1. エクスプローラー（Mac の場合は Finder）でこのフォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

### 方法 2：ブラウザを指定して開く

1. `index.html` を右クリックします。
2. 「プログラムから開く」を選び、使用したいブラウザ（Chrome・Edge・Firefox など）を選択します。

### 方法 3：ブラウザにドラッグ＆ドロップする

1. ブラウザを起動します。
2. `index.html` をブラウザのウィンドウにドラッグ＆ドロップします。

### 方法 4：コマンドから開く

フォルダに移動したうえで、お使いの環境に合わせて以下のコマンドを実行します。

```bash
# Windows（PowerShell / コマンドプロンプト）
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 補足

- Web フォント（Google Fonts）を読み込んでいるため、インターネットに接続した状態で開くと本来のデザインで表示されます。オフラインでも閲覧はできますが、フォントは端末の標準フォントになります。
- スマートフォン表示を確認したい場合は、ブラウザの開発者ツール（`F12` キー）を開き、デバイスツールバー（Chrome / Edge では `Ctrl + Shift + M`）で画面幅を切り替えてください。
